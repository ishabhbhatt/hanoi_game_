# Tower of Hanoi Game 🗼

## About the Project
Tower of Hanoi is a classic mathematical puzzle game developed using Python. The objective is to move all disks from the first tower to the third tower while following specific game rules.

This project is developed as a beginner-friendly Python mini-project to understand lists, dictionaries, functions, loops, conditional statements, and exception handling.

## Features
- Interactive command-line gameplay
- User-defined number of disks
- Three towers (A, B, C)
- Automatic move validation
- Move counter
- Minimum moves calculation
- Invalid input handling
- Winning condition detection

## Game Rules
1. Only one disk can be moved at a time.
2. Only the top disk of a tower can be moved.
3. A bigger disk cannot be placed on a smaller disk.
4. Move all disks from Tower A to Tower C to win.

## Technologies Used
- Python 3
- Lists
- Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Open the project folder:

   `cd tower-of-hanoi-python`

3. Run the Python file:

   `python hanoi.py`

## Minimum Moves Formula

The minimum number of moves required to solve the puzzle is:

**2ⁿ - 1**

Where n represents the number of disks.

## Example
For 3 disks, the minimum number of moves is 7.
